# 건물부수기 리메이크 (KiruBiru Remake)

## 기능 요구 사항
- 플레이어는 좌우 이동, 공격, 방어, 점프, 필살기를 사용할 수 있다
- 건물은 하늘에서 낙하하며, 층 단위로 파괴된다
- 일반 공격 시 최하단 1개 층을 파괴하고, 차징 공격 시 최하단 2개 층을 동시 파괴한다
- 공격 성공 시 콤보와 점수가 증가하고, 3초 이내 연속 공격 시 콤보 유지된다
- 방어 실패 시 목숨이 감소하며, 목숨이 0이 되면 게임오버된다
- 시간 경과에 따라 건물 낙하 속도가 점진적으로 증가한다
- 필살기 게이지가 100% 이상일 때 발동 가능하며, 화면 내 모든 건물을 파괴한다
- 최고 점수를 로컬 파일에 저장하고 불러온다
- 잘못된 입력이나 비정상 상태는 무시하고 게임 루프는 계속된다

## 구현할 기능 목록

### 게임 초기화 및 시작
- [ ] 게임 시작 시 초기 상태를 설정한다
    - 점수 0
    - 콤보 0
    - 게이지 0%
    - 목숨 3개
    - 기본 낙하 속도 설정
- [ ] 최고 점수를 로컬 파일에서 불러온다
- [ ] 시작 화면을 출력한다
    - 게임 제목
    - 최고 기록
    - 조작 안내 ([ENTER] 시작, [Q] 종료)
- [ ] ENTER 입력 시 게임을 시작한다
- [ ] Q 입력 시 프로그램을 종료한다

### 게임 루프
- [ ] 일정 프레임(fps)으로 update() 루프를 실행한다
- [ ] 매 프레임마다 다음 작업을 수행한다
    - 입력 처리
    - 플레이어 상태 갱신
    - 건물 위치 갱신
    - 충돌 판정
    - UI 출력
- [ ] 목숨이 0이 되면 게임오버 상태로 전환한다
- [ ] 게임오버가 아닌 동안 루프를 계속 실행한다

### 플레이어 시스템 (기본 조작)
- [ ] ← 키 입력 시 캐릭터를 왼쪽으로 이동한다
- [ ] → 키 입력 시 캐릭터를 오른쪽으로 이동한다
- [ ] 화면 경계를 벗어나지 않도록 이동을 제한한다
- [ ] Z 키 입력 시 일반 공격 모션을 실행한다
    - 캐릭터 바로 위 건물의 최하단 층 1개를 파괴
    - 공격 범위 내 건물이 있는지 확인
- [ ] ↓ 키 입력 시 방어 자세를 취한다
    - 방어 중 상태를 true로 설정
    - 방어 모션 출력
- [ ] ↑ 키 입력 시 점프한다
    - 점프 중 상태를 true로 설정
    - 점프 시간 동안 충돌 무시
    - 점프 시간 종료 후 원위치
- [ ] X 키 입력 시 필살기 발동을 시도한다
    - 게이지가 100% 이상인지 확인
    - 조건 충족 시 필살기 실행

### 플레이어 시스템 (리메이크 확장)
- [ ] ↑↑ 연속 입력 시 이단 점프를 수행한다
    - 첫 번째 점프 중 두 번째 ↑ 입력 감지
    - 이단 점프 가능 상태인지 확인
    - 공중에서 추가 점프 실행
- [ ] Z 키 홀드 시 차징 공격을 준비한다
    - Z 키 누른 시간을 측정
    - 1초 이상 홀드 시 차징 완료 상태로 전환
    - 차징 UI 표시 (게이지 또는 이펙트)
- [ ] 차징 완료 후 Z 키 릴리즈 시 차징 공격을 실행한다
    - 최하단 2개 층을 동시 파괴
    - 차징 상태 초기화

### 공격 시스템 (일반 공격)
- [ ] 공격 범위 내 건물이 있는지 확인한다
    - 캐릭터 x 좌표 기준 일정 범위
    - 캐릭터 바로 위 y 좌표
- [ ] 범위 내 건물의 최하단 층을 찾는다
- [ ] 최하단 층 1개를 파괴한다
    - 파괴 이펙트(`*`) 표시
    - 일정 시간 후 이펙트 제거
    - 층 목록에서 제거
- [ ] 공격 성공 시 콤보를 증가시킨다
- [ ] 마지막 공격 시간을 기록한다

### 공격 시스템 (차징 공격)
- [ ] 공격 범위 내 건물이 있는지 확인한다
- [ ] 범위 내 건물의 최하단 2개 층을 찾는다
- [ ] 최하단 층부터 2개를 동시 파괴한다
    - 건물에 층이 1개만 있으면 1개만 파괴
    - 건물에 층이 2개 이상이면 2개 파괴
    - 각 층에 파괴 이펙트(`*`) 표시
    - 일정 시간 후 이펙트 제거
    - 층 목록에서 제거
- [ ] 공격 성공 시 콤보를 증가시킨다
- [ ] 마지막 공격 시간을 기록한다

### 방어 시스템
- [ ] 방어 중 건물이 캐릭터와 충돌하는지 확인한다
- [ ] 충돌 시 방어 성공 처리를 한다
    - 건물을 위로 튕겨낸다 (y 좌표 증가)
    - 방어 성공 메시지 출력
    - 콤보 유지
- [ ] 방어 중이 아닐 때 충돌 시 방어 실패 처리를 한다
    - 건물을 위로 튕겨낸다
    - 목숨 -1
    - 콤보 초기화
    - 충돌 메시지 출력

### 건물 시스템
- [ ] Building 클래스로 건물을 관리한다
    - x, y 좌표
    - 층(Floor) 리스트
    - 낙하 속도
- [ ] Floor 클래스로 각 층을 관리한다
    - 위치 인덱스
    - 파괴 상태
- [ ] 화면 상단 랜덤 x 좌표에서 건물을 생성한다
- [ ] 건물에 3~5개의 층을 랜덤으로 추가한다
- [ ] 매 프레임마다 건물의 y 좌표를 낙하 속도만큼 증가시킨다
- [ ] 건물이 화면 하단을 벗어나면 제거한다
- [ ] 건물의 모든 층이 파괴되면 건물을 제거한다
- [ ] 일정 시간 간격으로 새 건물을 생성한다

### 낙하 속도 증가 시스템
- [ ] 게임 시작 후 경과 시간을 측정한다
- [ ] 일정 시간(예: 10초)마다 낙하 속도를 증가시킨다
    - 초기 속도: 1
    - 증가율: 0.1 ~ 0.2
    - 최대 속도: 5
- [ ] 현재 낙하 속도를 새로 생성되는 건물에 적용한다

### 콤보 시스템
- [ ] 공격 성공 시 콤보 카운트를 +1 증가시킨다
- [ ] 마지막 공격으로부터 3초 경과 시 콤보를 초기화한다
- [ ] 방어 실패(충돌) 시 콤보를 즉시 초기화한다
- [ ] 현재 콤보 수를 UI에 "x{콤보수}" 형식으로 표시한다

### 점수 시스템
- [ ] 층 파괴 시 기본 점수를 부여한다
    - 기본 점수: 100점
- [ ] 콤보 배율을 점수에 적용한다
    - 획득 점수 = 기본 점수 × (1 + 콤보 수 × 0.1)
- [ ] 건물 완전 파괴 시 보너스 점수를 부여한다
    - 보너스: 500점
- [ ] 필살기로 건물 파괴 시 추가 보너스를 부여한다
    - 파괴된 건물 개수 × 300점
- [ ] 총 점수를 누적하여 관리한다
- [ ] 점수를 천 단위 구분자(,)와 함께 출력한다

### 필살기 게이지 시스템
- [ ] 층 파괴 시 게이지를 충전한다
    - 1층 파괴 = +10%
- [ ] 건물 완전 파괴 시 추가 게이지를 충전한다
    - +20%
- [ ] 게이지가 100%를 초과할 수 있도록 한다
- [ ] 게이지를 UI에 시각적으로 표시한다
    - 10칸 바 형태 (예: ██████░░░░)
    - 백분율 표시 (예: 70%)
- [ ] X 키 입력 시 게이지가 100% 이상인지 확인한다
- [ ] 조건 충족 시 필살기를 발동한다

### 필살기 발동 시스템
- [ ] 필살기 발동 시 특수 이펙트를 출력한다
    - 화면 중앙에 "⚡ 필살기 발동! ⚡" 메시지
    - 테두리 박스 표시
- [ ] 화면 내 모든 건물의 모든 층을 파괴한다
    - 각 층에 파괴 이펙트 표시
- [ ] 파괴된 건물 개수를 집계한다
- [ ] 필살기 보너스 점수를 계산하여 추가한다
- [ ] 게이지를 0%로 초기화한다
- [ ] 필살기 발동 메시지를 출력한다

### 목숨 시스템
- [ ] 게임 시작 시 목숨을 3개로 설정한다
- [ ] 방어 실패(충돌) 시 목숨을 -1 감소시킨다
- [ ] 목숨이 0 이하가 되면 게임오버 상태로 전환한다
- [ ] 목숨을 UI에 하트(❤) 기호로 표시한다
    - 남은 목숨: ❤ (빨간 하트)
    - 잃은 목숨: ♡ (빈 하트)

### 충돌 판정 시스템
- [ ] 매 프레임마다 캐릭터와 건물 간 충돌을 검사한다
- [ ] 건물의 최하단 층이 캐릭터의 y 좌표에 도달했는지 확인한다
- [ ] 건물의 x 좌표와 캐릭터의 x 좌표가 겹치는지 확인한다
    - 충돌 범위: 캐릭터 너비 ±1
- [ ] 점프 중일 때는 충돌을 무시한다
- [ ] 충돌 감지 시 방어 중 여부를 확인한다
    - 방어 중: 방어 성공 처리
    - 방어 중 아님: 방어 실패 처리

### 기록 저장 시스템
- [ ] HighScoreManager 클래스로 기록을 관리한다
- [ ] 게임 시작 시 "highscore.txt" 파일에서 최고 점수를 불러온다
- [ ] 파일이 없거나 읽기 실패 시 최고 점수를 0으로 초기화한다
- [ ] 게임오버 시 현재 점수와 최고 점수를 비교한다
- [ ] 현재 점수가 최고 점수보다 높으면 갱신한다
- [ ] 갱신된 최고 점수를 파일에 저장한다
- [ ] 신기록 달성 시 축하 메시지를 출력한다

### UI 출력 시스템
- [ ] 화면 상단에 게임 정보를 출력한다
    - 점수 (천 단위 구분자)
    - 콤보 (x{콤보수})
    - 게이지 (바 + 백분율)
    - 목숨 (하트 기호)
- [ ] 게임 화면 영역을 출력한다
    - 건물: ▩▩▩
    - 캐릭터: @
    - 일반 공격 모션: @⚔️↑
    - 차징 준비 모션: @⚡
    - 차징 공격 모션: @⚔️⚔️↑
    - 방어 모션: @↓🛡️
    - 파괴 이펙트: ***
    - 필살기 이펙트: 중앙 박스 + 메시지
- [ ] 하단에 조작 안내를 출력한다
    - [←→]이동 [Z]공격 [↓]방어 [↑]점프 [X]필살기
- [ ] 이벤트 메시지를 출력한다
    - [HIT!] 1개 층 파괴! 콤보 +1
    - [차징 중...] {시간}초
    - [차징 공격!] 2개 층 동시 파괴! 콤보 +1
    - [방어 성공!] 건물을 막아냈습니다!
    - [충돌!] 목숨 -1, 콤보 초기화!
    - 모든 건물 파괴! +{점수} 보너스!
- [ ] 콘솔 화면을 지우고 다시 그린다 (깜빡임 최소화)

### 게임오버 시스템
- [ ] 목숨이 0이 되면 게임오버 화면을 출력한다
- [ ] 게임오버 정보를 표시한다
    - 최종 점수
    - 최고 콤보
    - 플레이 시간 (분:초)
    - 남은 목숨
- [ ] 신기록 달성 시 특별 메시지를 표시한다
    - ★ 새로운 최고 기록 달성! ★
    - 이전 기록: {점수}점
- [ ] 재시작 및 종료 옵션을 제공한다
    - [R] 재시작
    - [Q] 종료
- [ ] R 입력 시 게임을 초기화하고 재시작한다
- [ ] Q 입력 시 프로그램을 종료한다

### 예외 처리 및 검증
다음 상황에서는 에러 메시지를 출력하지 않고 무시하거나 복구한다:

**입력 관련:**
- [ ] 지원하지 않는 키 입력 시 무시한다
- [ ] 동시에 여러 키가 입력되면 우선순위를 적용한다
    - 필살기 > 공격 > 방어 > 점프 > 이동

**상태 관련:**
- [ ] 점수가 음수가 되지 않도록 0으로 고정한다
- [ ] 콤보가 음수가 되지 않도록 0으로 고정한다
- [ ] 게이지가 음수가 되지 않도록 0으로 고정한다
- [ ] 목숨이 음수가 되지 않도록 0으로 고정한다

**건물 관련:**
- [ ] 건물 생성 시 x 좌표가 화면 범위 내에 있도록 제한한다
- [ ] 건물이 화면 밖으로 나가면 자동 제거한다
- [ ] 층이 0개인 건물은 자동 제거한다

**층 파괴 관련:**
- [ ] 차징 공격 시 건물에 층이 1개만 있으면 1개만 파괴한다
- [ ] 차징 공격 시 건물에 층이 2개 이상이면 2개 파괴한다
- [ ] 이미 파괴된 층에 대한 중복 파괴 시도를 무시한다

**속도 관련:**
- [ ] 낙하 속도가 최대값을 초과하지 않도록 제한한다
- [ ] 낙하 속도가 음수가 되지 않도록 0으로 고정한다

**파일 관련:**
- [ ] 최고 점수 파일 읽기 실패 시 기본값 0 사용
- [ ] 최고 점수 파일 쓰기 실패 시 경고 메시지만 출력하고 계속 진행

**게임 루프 관련:**
- [ ] 예외 발생 시 루프를 중단하지 않고 계속 실행한다
- [ ] 크리티컬 에러 발생 시에만 게임오버 처리한다

### 테스트 (GTest 기반)

**단위 테스트 대상:**
- [ ] Floor 클래스의 파괴 판정
- [ ] Building 클래스의 층 추가 및 제거
- [ ] 일반 공격 시 최하단 1개 층 파괴 로직
- [ ] 차징 공격 시 최하단 2개 층 파괴 로직
- [ ] 차징 공격 시 층이 1개만 있을 때 1개만 파괴 로직
- [ ] 건물의 모든 층 파괴 시 건물 제거 로직
- [ ] 공격 시 콤보 증가 로직
- [ ] 3초 경과 시 콤보 초기화 로직
- [ ] 방어 실패 시 콤보 초기화 로직

### 기타 고려 사항
- enum class를 사용하여 상태를 관리한다
    - GameState: MENU, PLAYING, GAME_OVER
    - InputKey: LEFT, RIGHT, ATTACK, DEFEND, JUMP, ULTIMATE, QUIT
    - PlayerState: IDLE, MOVING, ATTACKING, CHARGING, DEFENDING, JUMPING
    - AttackType: NORMAL (1개 층), CHARGED (2개 층)
- 함수는 한 가지 일만 수행하도록 작게 분리한다
- indent depth는 2를 넘지 않도록 한다
- else, switch/case, 삼항 연산자를 사용하지 않는다
- 함수 길이는 10라인을 넘지 않도록 한다
- Google C++ Style Guide를 준수한다
- 의미 있는 변수명과 함수명을 사용한다
- 주석은 "왜"를 설명하되, "무엇"은 코드로 표현한다
- 차징 공격과 일반 공격의 차이를 명확히 구분한다
    - 일반: Z 탭 → 1개 층 파괴
    - 차징: Z 홀드(1초+) → 2개 층 파괴
